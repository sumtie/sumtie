支持字段：vless 与 trojan 走 security=tls&type=ws&host=&path=&sni=&fp=&alpn= 这类 Xray 标准参数； shadowsocks 支持标准 SIP002 链接（ss://method:password@host:port 或 base64 形式），ws+tls 通过 plugin=v2ray-plugin;mode=websocket;tls;host=;path= 或等价的 security=tls&type=ws 查询参数识别， 输出时会转换为 Mihomo 的 plugin: v2ray-plugin 写法。
ECH：vless / trojan 链接中若带有 ech=1 搭配 ech-config-list=（或 echConfigList / ech-config 等等价写法，base64 / base64url 均可）会自动识别，并输出 Mihomo 的 ech-opts: {enable: true, config: ...}；只写 ech=1 而不带配置值时，会输出 enable: true，交由 Mihomo 通过 DNS 自动解析 ECH 配置。ECH 依附于原生 TLS，故仅对 vless / trojan 生效，v2ray-plugin 承载的 shadowsocks 不支持该字段。
