生成结果 03 · 输出

vmess:// … +ws +tls vless:// … +ws +tls ss:// … +ws +tls trojan:// … +ws +tls tuic:// hysteria2:// / hy2:// ECH / ech-opts

输入链接 转换

支持 VMess / VLESS / Shadowsocks / Trojan（WS+TLS）、TUIC、Hysteria2 分享链接，一键转换为 Mihomo (Clash Meta) YAML 节点。若链接含 ECH 参数，将自动写入 ech-opts。

Mihomo 输出 YAML

可将结果粘贴到 Mihomo / Clash Meta 配置的 proxies: 段。VMess 支持标准 Base64 JSON 链接；ECH 参数支持链接中的 ech / ech-config / ech-query-server-name；会自动转为标准 base64 的 ech-opts.config。TUIC / Hysteria2 为 QUIC 协议，无需 WS。
